## Featured Project: Deep Learning Framework Comparison

**Status:** Completed coursework

Conducted a comparative analysis of major deep learning frameworks,
examining their design philosophies, strengths, limitations,
and practical applications.

My assigned comparisons included:

- TensorFlow vs. PyTorch
- PyTorch vs. fastai

The project included research, technical documentation, and
hands-on experimentation using image classification.

Key areas of analysis included:
- Framework usability and flexibility
- Model development workflows
- Training and evaluation
- Practical applications
- Trade-offs between high-level and low-level frameworks
